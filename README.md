# Progetto Machine Learning and Data Analysis — Diabetes Health Indicators (BRFSS 2015)

Classificazione multiclasse dello stato di diabete a partire da indicatori sanitari, abitudini di vita e caratteristiche demografiche.

## Obiettivo

Costruire e valutare modelli di machine learning supervisionato per predire lo stato di diabete di un individuo (No diabetes / Prediabetes / Diabetes) utilizzando il dataset **BRFSS 2015** (*Behavioral Risk Factor Surveillance System*).

## Dataset

**Diabetes Health Indicators Dataset** — disponibile su Kaggle:  
https://www.kaggle.com/datasets/alexteboul/diabetes-health-indicators-dataset

## Tecnologie utilizzate

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
